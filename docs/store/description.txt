Metatron
Local Claude Code CLI in your browser.

Metatron connects a browser side panel to Claude Code running locally in your project. Chat, review streaming replies and tool calls, approve permissions, and attach browser context without switching to a terminal. By Alexey Fedorov.

SETUP

The npm package and CLI command remain claude-studio. From the project you want to work on, run:

  pnpm dlx claude-studio@3

Or choose a project explicitly:

  pnpm dlx claude-studio@3 --project /path/to/your/project

Open the Metatron side panel and connect to ws://127.0.0.1:7281, the default daemon URL. Keep the daemon running while using the panel. It is headless; the browser panel provides chat, settings, and approvals.

FEATURES

- Claude Code in your browser: Chat with Claude Code in one project using your normal project instructions, memory, MCP servers, skills, plugins, and hooks.
- Browser context: Attach page information, selected text, page text, a screenshot of the visible tab, or a picked element's selector, styles, and structure. Review pending attachments before sending.
- Streaming chat: Read replies, reasoning when available, tool calls, tool results, and permission prompts in the side panel.
- Saved conversations: List and resume real Claude Code sessions for your project, including conversations started in a terminal. Closing the panel does not stop a live session.
- Model and effort settings: Choose from the models and options reported by Claude Code. Connected panels share daemon settings.
- Permission and budget controls: Set a permission mode, maximum turns, and an optional cumulative USD budget for a live Claude Code process. Process restart, idle eviction, or conversation clear (/clear) gives a fresh budget allowance.
- Usage visibility: See token usage and per-turn cost reported by Claude Code.

REQUIREMENTS

- Node.js 20 or newer and pnpm for the daemon command above.
- Claude Code authentication on the daemon machine, or a supported API-provider configuration. The agent package supplies its Claude Code runtime through the Claude Agent SDK.
- A Chromium-based browser with the side panel API, such as Chrome or Brave.
- A protocol-v3 Metatron extension and claude-studio 3.x daemon. Upgrade them together.

PRIVACY

Browser capture is user-triggered, and attachments stay pending in the browser until you send them. The extension stores settings, drafts, and sent-message recall locally; Claude Code stores durable transcripts on the daemon machine. New chats and conversation clears do not erase those transcripts.

The extension sends messages and attachments to the daemon URL you configure, defaulting to ws://127.0.0.1:7281. Local execution does not mean all data stays local: Claude Code sends context to your model provider and may use configured tools and integrations that process data remotely. Review captures and your configuration before sending sensitive information.

The extension and daemon do not add a separate analytics service; normal Claude Code and SDK telemetry settings still apply. The website uses Vercel Analytics. See PRIVACY.md in the repository for storage, permissions, and third-party processing details.

FAQ

What is Metatron?
Local Claude Code CLI in your browser. It is a browser extension plus a local daemon that connects the side panel to Claude Code in your project.

Did the install command change?
No. The npm package and CLI command remain claude-studio. Existing ~/.claude-studio settings paths and CLAUDE_STUDIO_* environment variables are unchanged.

Does Metatron send my code anywhere?
Messages and attached browser context go to your configured daemon. Claude Code processes them using your normal settings. Model providers, MCP servers, and other integrations can receive code or context under your configuration and their own policies.

Is Metatron free?
Metatron is free to use under the Elastic License 2.0. Claude Code account or provider usage charges still apply.
